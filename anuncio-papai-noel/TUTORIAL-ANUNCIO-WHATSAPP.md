# Do vídeo à primeira venda
### Tutorial de anúncio no Facebook/Instagram → WhatsApp — Vídeos do Papai Noel

> **Antes de começar:** onde estiver **[ENTRE COLCHETES]**, troque pelo seu dado (preço, chave Pix, prazo). Os nomes dos menus da Meta podem mudar um pouco, mas o caminho é sempre o mesmo.

---

## Visão geral (6 etapas)

| # | Etapa | Tempo |
|---|---|---|
| 1 | Configurar o WhatsApp Business | 15 min |
| 2 | Conectar o WhatsApp à Página | 5 min |
| 3 | Criar a campanha no Gerenciador de Anúncios | 20 min |
| 4 | Aprovação e primeiros dias | 1 a 3 dias |
| 5 | Atender o cliente no WhatsApp (roteiro pronto) | — |
| 6 | Entregar, pedir indicação e escalar | — |

## ETAPA 1 — Configurar o WhatsApp Business

Abra o **WhatsApp Business** → **⋮ (ou Configurações)** → **Ferramentas comerciais**.

### 1.1 Perfil comercial
- **Nome:** Vídeos do Papai Noel – Jonathan
- **Categoria:** Entretenimento (ou Serviços)
- **Foto:** um frame bonito do Papai Noel do seu vídeo
- **Descrição:**
  > 🎅 Vídeos personalizados do Papai Noel falando o NOME do seu filho! Mensagem exclusiva e emocionante. Vagas limitadas para o Natal. ✨
- **Horário:** o horário em que você consegue responder

### 1.2 Mensagem de saudação (automática)
**Ferramentas comerciais → Mensagem de saudação → Ativar → "Todos"**

```
Ho, ho, ho! 🎅🎄
Que alegria receber sua mensagem! Aqui é o Jonathan, da equipe do Papai Noel.

Em instantes vou te atender pessoalmente. Enquanto isso, me conta:
1️⃣ Qual o nome da criança?
2️⃣ Quantos anos ela tem?

⚠️ As vagas para entrega antes do Natal são limitadas!
```

### 1.3 Mensagem de ausência (automática)
**Ferramentas comerciais → Mensagem de ausência → Ativar → "Fora do horário comercial"**

```
Ho, ho, ho! 🎅 Recebi sua mensagem!
No momento o Papai Noel está na oficina, mas amanhã cedinho eu te respondo.
Já pode me mandar o nome e a idade da criança que eu reservo seu lugar na fila! 🎁
```

### 1.4 Respostas rápidas (atalhos)
**Ferramentas comerciais → Respostas rápidas → +**. Depois, na conversa, é só digitar **/** e escolher. Os textos de cada atalho estão na **Etapa 5**.

| Atalho | Uso |
|---|---|
| `/oferta` | Explica o produto e o preço |
| `/dados` | Pede as informações da criança |
| `/pix` | Envia a forma de pagamento |
| `/confirmado` | Confirma o pedido pago |
| `/entrega` | Envia o vídeo pronto |
| `/lembrete` | Retoma quem parou de responder |
| `/indica` | Pede indicação |

### 1.5 Etiquetas (organizar clientes)
**Ferramentas comerciais → Etiquetas** e crie:

🟡 **Novo contato** · 🔵 **Aguardando pagamento** · 🟢 **Pago – produzir** · 🟣 **Entregue** · 🔴 **Sumiu (retomar)**

### 1.6 Catálogo (opcional, mas recomendado)
**Ferramentas comerciais → Catálogo → Adicionar item**
- **Nome:** Vídeo Personalizado do Papai Noel
- **Preço:** [R$ XX]
- **Descrição:** Vídeo exclusivo com o Papai Noel falando o nome da criança e uma mensagem especial. Entrega em até [X] dias.
- **Imagem:** frame do vídeo

## ETAPA 2 — Conectar o WhatsApp à Página

1. Abra a **Página** no Facebook → **Configurações** → **Contas vinculadas** → **WhatsApp**.
2. Digite **o mesmo número do WhatsApp Business** → **Enviar código**.
3. Digite o código que chegou → **Confirmar**.
4. Confira se a Página está no seu **Portfólio empresarial** (business.facebook.com → Configurações → Contas → Páginas), junto com a conta de anúncios.

✅ Pronto quando aparecer "WhatsApp conectado" na Página.

---

## ETAPA 3 — Criar a campanha (Gerenciador de Anúncios)

Acesse **adsmanager.facebook.com** → botão verde **+ Criar**.

### 3.1 Campanha
| Campo | O que colocar |
|---|---|
| Objetivo | **Engajamento** |
| Nome da campanha | `Papai Noel – WhatsApp – Nov` |
| Orçamento Advantage+ da campanha | Desligado (você define no conjunto) |

→ **Avançar**

### 3.2 Conjunto de anúncios
| Campo | O que colocar |
|---|---|
| Nome | `Pais 25-50 – [Sua cidade/Brasil]` |
| Local da conversão | **Apps de mensagens** |
| Apps de mensagens | Marque só **WhatsApp** |
| Página | Sua Página |
| Número do WhatsApp | O número conectado |
| Meta de desempenho | Maximizar o número de conversas |
| Orçamento | **Diário: R$ 20 a R$ 30** para começar |
| Programação | Começar hoje, sem data de término |
| Localização | Brasil (ou seu estado/cidade, se atender só local) |
| Idade | **25 a 50 anos** |
| Gênero | Todos |
| Público | Deixe o **Advantage+** ligado (a Meta acha os compradores) |
| Posicionamentos | **Advantage+** (automático) |

→ **Avançar**

### 3.3 Anúncio
| Campo | O que colocar |
|---|---|
| Nome do anúncio | `Vídeo Papai Noel – V1` |
| Identidade | Sua Página (+ Instagram, se tiver conectado) |
| Configuração | Criar anúncio → **Imagem ou vídeo único** |
| Mídia | Suba o vídeo **9:16** (vertical) |
| Chamada para ação | **Enviar mensagem pelo WhatsApp** |

**Texto principal** (copie um, depois teste o outro):

**Versão A**
```
🎅 Seu filho vai receber um vídeo do PAPAI NOEL falando o NOME dele!

Uma mensagem personalizada, emocionante, que ele vai guardar para sempre. ❤️

✅ O Papai Noel fala o nome da criança
✅ Mensagem exclusiva e especial
✅ Entrega pelo WhatsApp antes do Natal

⚠️ Vagas limitadas! Clique em "Enviar mensagem" e fale com o Jonathan agora. 👇
```

**Versão B (mais curta)**
```
Imagina a carinha do seu filho ouvindo o Papai Noel chamar ele pelo nome... 🎅✨

Vídeo personalizado, entregue no seu WhatsApp antes do Natal.
As vagas são limitadas — garanta a sua agora! 👇
```

**Título:** `Vídeo do Papai Noel com o nome do seu filho 🎅`
**Descrição:** `Vagas limitadas para o Natal`

### 3.4 Modelo de mensagem (o que o cliente vê ao clicar)
Na seção **Modelo de mensagem → Criar novo**:

- **Saudação:** `Ho, ho, ho! 🎅 Quer um vídeo do Papai Noel para seu filho? Toque em uma opção abaixo!`
- **Perguntas frequentes (botões):**
  1. `Quero o vídeo para meu filho! 🎅`
  2. `Quanto custa?`
  3. `Como funciona?`
  4. `Chega antes do Natal?`

> Cada botão vira a primeira mensagem do cliente. Assim você já sabe que ele veio do anúncio e o que ele quer.

→ **Publicar** ✅

## ETAPA 4 — Aprovação e primeiros dias

- **Aprovação:** normalmente de minutos a 24 h. Se reprovar, veja o motivo em "Qualidade da conta" e ajuste o texto.
- **Não mexa na campanha nos primeiros 3 dias.** É a fase de aprendizado. Alterar reinicia tudo.
- **Responda rápido.** Quem responde em até 5 minutos vende muito mais. Deixe as notificações ligadas.

### O que olhar (coluna "Custo por conversa iniciada")
| Resultado | O que fazer |
|---|---|
| Conversas baratas e gente comprando | Aumente o orçamento **20% a cada 2–3 dias** |
| Conversas baratas, mas ninguém compra | O problema é o atendimento ou o preço → revise a Etapa 5 |
| Conversas caras ou poucas, após 3 dias | Teste o Texto B ou um novo vídeo no mesmo conjunto |

## ETAPA 5 — Atendimento no WhatsApp (roteiro de venda)

**Fluxo:** Saudação automática → `/oferta` → `/dados` → `/pix` → `/confirmado` → produzir → `/entrega` → `/indica`

### `/oferta` — explicar e dar o preço
```
Que bom ter você aqui! 😊🎄

Funciona assim:
🎅 O Papai Noel grava um vídeo exclusivo falando o NOME da criança
💌 Ele conta que ela se comportou bem e deixa uma mensagem especial
📲 Você recebe o vídeo aqui no WhatsApp, pronto para mostrar

💰 Valor: [R$ XX]
⏰ Entrega em até [X] dias

⚠️ As vagas para antes do Natal são limitadas e estão acabando.
Posso garantir a vaga da sua criança?
```

### `/dados` — informações para o vídeo
```
Perfeito! Para o Papai Noel deixar a mensagem bem especial, me manda:

1️⃣ Nome da criança (e como ela é chamada em casa, se tiver apelido)
2️⃣ Idade
3️⃣ Algo que ela fez de bom este ano (ex.: ajudou em casa, foi bem na escola)
4️⃣ O presente que ela pediu (opcional)
5️⃣ Nome de irmãos ou do pet (opcional)

Assim que você me passar, já envio a forma de pagamento para reservar a vaga! 🎁
```

### `/pix` — pagamento
```
Prontinho, anotei tudo! 📝

Para garantir a vaga é só fazer o Pix:
🔑 Chave Pix: [SUA CHAVE]
👤 Nome: [SEU NOME]
💰 Valor: [R$ XX]

Assim que pagar, me manda o comprovante aqui que eu já coloco o pedido na produção do Papai Noel! 🎅✨
```

### `/confirmado` — pedido pago
```
Pagamento confirmado! ✅🎉
O pedido da [NOME DA CRIANÇA] já está na oficina do Papai Noel.

📅 Você recebe o vídeo até [DATA].
Qualquer dúvida, estou por aqui! Muito obrigado pela confiança. ❤️🎄
```

### `/entrega` — vídeo pronto
```
Ho, ho, ho! 🎅 O vídeo da [NOME DA CRIANÇA] ficou pronto!

Aqui está 👇 Prepare o celular para filmar a reação dela. Vai ser emocionante! 😍

Se puder, me manda depois o vídeo da reação. O Papai Noel adora ver! 🎁
```

### `/lembrete` — para quem parou de responder (mande 1 dia depois)
```
Oi! 😊 Passando para avisar que ainda consigo segurar a vaga da sua criança, mas as vagas para antes do Natal estão quase no fim. 🎅⏰

Quer que eu reserve para você?
```

### `/indica` — pedir indicação (logo após a entrega)
```
Que bom que vocês gostaram! ❤️

Tem algum amigo, parente ou mãe da escola que ia amar isso também? 🎄
Se indicar e a pessoa fechar, você ganha [BÔNUS: ex. R$ 10 de volta / vídeo para irmão com desconto].

É só me passar o contato ou compartilhar meu número: [SEU NÚMERO] 🎅
```

### Respostas para dúvidas comuns
| Cliente diz | Você responde |
|---|---|
| "Tá caro" | "Entendo! Pensa que é um presente que ele vai rever todo Natal, e a reação não tem preço 😍. Para irmãos faço [R$ XX] no segundo vídeo." |
| "Vou pensar" | "Claro! Só aviso que as vagas para antes do Natal estão acabando. Quer que eu segure a sua até amanhã?" |
| "É de verdade / é seguro?" | Mande um vídeo de exemplo + "Você só paga depois de me passar os dados, e o vídeo chega aqui mesmo no WhatsApp." |
| "Dá para ser mais de uma criança?" | "Dá sim! Cada criança tem seu vídeo com o próprio nome. Para 2 ou mais faço [CONDIÇÃO]." |

## ETAPA 6 — Primeira venda e próximos passos

**Checklist da primeira venda**
- [ ] Cliente respondeu → etiqueta 🟡 **Novo contato**
- [ ] Enviou `/oferta` e `/dados`
- [ ] Mandou `/pix` → etiqueta 🔵 **Aguardando pagamento**
- [ ] Recebeu o comprovante → `/confirmado` → etiqueta 🟢 **Pago – produzir**
- [ ] Gerou o vídeo e enviou com `/entrega` → etiqueta 🟣 **Entregue**
- [ ] Mandou `/indica`
- [ ] Pediu autorização para usar a reação como depoimento (ótimo para novos anúncios)

**Para escalar**
1. Com vendas acontecendo, aumente o orçamento **20% a cada 2–3 dias**.
2. Use os vídeos de reação (com autorização dos pais) como novo anúncio. Prova social vende muito.
3. A partir de **10 de dezembro**, reforce a urgência no texto: *"Últimas vagas para entrega antes do Natal!"*.

> **Cuidado com os dados:** você vai receber nomes de crianças. Peça só o necessário, não poste nada sem autorização dos pais e apague as informações depois da entrega.
