# Exemplos de edição — Aura Fresh

Suba aqui os pares de vídeo (GitHub → **Add file → Upload files**, até 25 MB por arquivo; se passar, exporte em 720p):

```
01-antes.mp4   ← UGC bruto, do jeito que chegou
01-depois.mp4  ← o mesmo vídeo depois de editado no CapCut
02-antes.mp4
02-depois.mp4
```

Se puder, coloque no nome o ângulo do vídeo: `03-bafo-antes.mp4` / `03-bafo-depois.mp4`, `04-cece-antes.mp4`...

Também ajudam (pode subir aqui mesmo):
- `logo.png` com fundo transparente
- fotos do produto (`produto-1.jpg`, `produto-2.jpg`...)
- músicas e efeitos sonoros que você costuma usar
