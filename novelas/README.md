# 🎬 Novelas

Pasta com tudo das novelas de IA: ideias, personagens, episódios e prompts.

- `banco-de-ideias.md` — 10 ideias de novela com o gancho do episódio 1
- Cada novela escolhida ganha a própria pasta, por exemplo `o-casamento/`:
  - `biblia.md` — personagens (aparência, segredos), história e o que já aconteceu
  - `ep01.md`, `ep02.md`… — cenas com os prompts prontos para o Flow

Padrão das cenas: Google Flow (Veo 3.1), 8 s por cena, vertical 9:16, falas em português do Brasil.
